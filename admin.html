📖 সেটআপ গাইড (একবার করলেই হবে)

১️⃣ GitHub Token

  1. যান: github.com/settings/personal-access-tokens/new
  2. Repository access: Only select repositories → online-hat
  3. Permissions → Repository → Contents: Read and write
  4. Generate করে নিচে পেস্ট করুন:

২️⃣ অর্ডার বুক (Google Sheet)

  1. sheets.new খুলুন → নাম দিন "Online Hat Orders"
  2. মেনু: Extensions → Apps Script
  3. আগের কোড মুছে google-apps-script-code.txt ফাইলের পুরো কোড পেস্ট করুন
  4. কোডের প্রথম লাইনে ADMIN_KEY বদলে নিজের secret দিন
  5. Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → Deploy
  6. Permission allow করুন → যে Web app URL পাবেন সেটা কপি করুন
  7. URL টা 📋 অর্ডার বুক ট্যাব ও ⚙️ সেটিংস ট্যাবে বসিয়ে সেভ করুন

এরপর থেকে প্রতিটা অর্ডার অটো Google Sheet এ জমা হবে — ফোনে Sheets অ্যাপ দিয়ে যেকোনো সময় দেখবেন। WhatsApp ব্যাকআপ হিসেবে আগের মতোই থাকবে।
