২️⃣ অর্ডার বুক — ২টা উপায় (যেকোনো একটা করলেই হবে)

🅰️ উপায় ১ (সবচেয়ে সহজ): অর্ডার সরাসরি আপনার ইমেইলে

  1. ⚙️ সেটিংস ট্যাবে যান → "অর্ডার ইমেইল" ফিল্ডে আপনার Gmail লিখুন
  2. পাবলিশ করুন চাপুন — ব্যস!
  3. প্রথম অর্ডার আসার পর FormSubmit নামে একটা ফ্রি সার্ভিস activation ইমেইল পাঠাবে → সেটার লিংকে ক্লিক করে নিশ্চিত করুন (একবারই)
  4. এরপর প্রতিটা অর্ডার আপনার ইনবক্সে টেবিল আকারে চলে আসবে 📬

🅱️ উপায় ২ (সেরা): Firebase — Admin Panel এ লাইভ অর্ডার টেবিল

  1. যান: console.firebase.google.com → Gmail দিয়ে লগইন → "Create a project" (Analytics বন্ধ রাখতে পারেন)
  2. বাম মেনু Build → Realtime Database → Create Database → Location: asia-south1 (Mumbai) → Start in test mode → Enable
  3. Database এর Rules ট্যাবে নিচের নিয়মটা বসিয়ে Publish করুন:
{"rules":{"orders":{".read":"auth != null",".write":true}}}
  1. বাম মেনু Build → Authentication → Get started → Email/Password চালু করে Save
  2. একই পেজে Users → Add user → আপনার email + একটা password দিন (এটাই Admin Panel লগইন)
  3. প্রজেক্ট সেটিংস ⚙️ → Your apps → Web (</> আইকন) → Register app (Firebase Hosting লাগবে না) → স্ক্রিপ্টে দেখা যাবে apiKey, databaseURL, projectId — এই ৩টা মান কপি করুন
  4. ⚙️ সেটিংস ট্যাবে এই ৩টা মান বসিয়ে পাবলিশ করুন
  5. 📋 অর্ডার বুক ট্যাবে গিয়ে ধাপ ৬ এর email/password দিয়ে লগইন করুন — অর্ডার লাইভ টেবিলে আসা শুরু হবে! 🔴

দুটোই করলে আরও ভালো — টেবিল + ইমেইল ব্যাকআপ দুটোই পাবেন। টাকা কোনোটায়ই লাগবে না।
